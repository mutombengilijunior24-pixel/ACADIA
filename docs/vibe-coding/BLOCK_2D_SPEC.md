# ACADIA — BLOCK 2D SPEC
# User validation

## Objective

Validate the whole Block 2 experience with real users instead of only code tests.

## Test group

First wave: 3–5 users.

## Task

Give each person a research topic and say:

> Create your research on ACADIA. Use the application without help unless you are blocked.

## Observe

- Where they hesitate.
- What they misunderstand.
- Where they expect AI help.
- Where they distrust the proposal.
- Which screens feel too long.
- Which labels are confusing.
- Whether they understand the progression.

## Acceptance

Block 2 is validated only when:

- users can complete the flow without developer intervention;
- AI proposals are understandable;
- users know what they can edit;
- no critical data is lost;
- the interface looks coherent across desktop and mobile.
